# TMAS — Museum of Abandoned Space

Хакатонный проект об аппаратах, оставшихся на Луне и Марсе. План демо включает две вращаемые 3D-модели и четыре истории миссий.

## Локальный запуск

Нужны Node.js и npm. Проект проверяется на Node.js 24.

```sh
npm ci
npm run dev
```

Откройте [localhost:3000](http://localhost:3000). Для проверки production-сборки запустите `npm run build`.
